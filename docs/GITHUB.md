# Размещение в GitHub

Проект готов к публикации как отдельный репозиторий. Включены исходный код, инструкции, синтетические примеры, автоматические тесты и GitHub Actions.

Для начала используйте **приватный** репозиторий `retail-ops-assistant`. Настоящие данные компании и ключи в него не добавляйте. Вопрос использования кода и данных внутри компании согласуйте с руководителем/ИТ.

## Через GitHub CLI

Нужны установленные Git и официальный [GitHub CLI](https://cli.github.com/). Распакуйте проект и откройте терминал в его папке.

```bash
gh auth login
git init -b main
git add .github .gitignore pyproject.toml README.md retail_ops tests config docs start_windows.bat start_macos.command
git commit -m "Add local retail operations assistant"
gh repo create retail-ops-assistant --private --source . --remote origin --push
```

Перед `git commit` проверьте `git diff --cached --stat`: должны быть только код, документация и синтетические CSV. Если Git просит имя/почту автора, задайте свои значения через `git config user.name` и `git config user.email`; GitHub позволяет использовать адрес noreply из настроек аккаунта.

Не повторяйте `gh repo create`, если репозиторий уже существует. Для существующего пустого репозитория используйте его фактический URL:

```bash
git remote add origin <URL-вашего-репозитория>
git push -u origin main
```

## Через подключение в ChatGPT

Создайте пустой приватный репозиторий в своём GitHub и предоставьте подключению GitHub доступ именно к этому репозиторию, затем передайте его ссылку в разговоре. Если подключение уже имеет доступ ко всем репозиториям, отдельное расширение не требуется. В доступном наборе инструментов есть запись файлов и коммитов, но нет операции создания нового репозитория.

## После публикации

Откройте вкладку Actions и дождитесь результата `Tests`. Workflow подготовлен для Python 3.11, 3.12 и 3.13. Пока workflow фактически не запущен в GitHub, не считайте его прошедшим. Локальные тесты проверяют выгрузки и приложение, не корпоративные интеграции.
